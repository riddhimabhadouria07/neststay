# NestStay PG

A modern frontend-only PG accommodation and booking website built with HTML, CSS and vanilla JavaScript.

## Run

1. Open the `neststay-pg` folder in VS Code.
2. Install/use **Live Server** if desired.
3. Open `index.html`.
4. Explore Rooms → Register → Student Dashboard.
5. Use `admin.html` for the demo admin dashboard.

## Important

This is a frontend demo. Login, registration, application data and theme preferences use `localStorage`. Real authentication, file storage, payments, live room availability and admin persistence require a backend/database.

## Customize

Search these values in the project:
- `NestStay PG` — brand
- `₹8,000` / `₹6,500` — room prices
- `+91 99999 99999` — phone
- `info@neststaypg.com` — email
- `123, College Road, Indore` — address
- `menu` array in `js/main.js` — weekly food menu
- Unsplash image URLs — room/PG imagery

## Suggested backend

For a production version, connect the frontend to Firebase, Supabase, Node/Express + MongoDB, or another backend for authentication, applications, room inventory, payments and document uploads.
